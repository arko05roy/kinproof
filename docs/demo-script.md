# Demo script

Use this three-minute outline for the public MVP walkthrough.

1. **Problem (0:00–0:25)** — Explain that a recovery plan is valuable but publishing it creates an attack map.
2. **Privacy boundary (0:25–0:50)** — Show the five checks. State that they are private ZK witnesses and that the app never asks for a seed phrase, trusted-contact name, backup location, or instructions.
3. **Live Preprod flow (0:50–1:55)** — Connect Lace on Midnight Preprod, complete all five checks, review the wallet request, and create a seal. Show the application status moving through proof generation and confirmation.
4. **Public verification (1:55–2:25)** — Show the public counters, contract address, and Preprod explorer. Explain that only an app-specific commitment, status, revision, and aggregate activity are public.
5. **Lifecycle (2:25–2:50)** — Refresh the proof or revoke the seal. Explain that refresh increments the revision and revoke marks the seal inactive without revealing plan changes.
6. **Evidence (2:50–3:00)** — Point to the README, CI workflow, contract address, 50-address cohort record, and feedback-loop documentation.
